# Acknowledgements

## Recognition

The development of **BasDonax Keyline from DEM** has benefited from the QGIS open-source ecosystem and the work of many contributors.

The author would like to express special thanks to the developer of the **Topo Drain Plugin**:

https://github.com/wickit7/topo-drain-plugin

whose publicly available documentation and user manuals were consulted during the preparation of this project documentation.

Some concepts related to documentation structure, workflow presentation and user guidance were inspired by the documentation accompanying the Topo Drain Plugin.

This acknowledgement refers exclusively to the documentation and does **not** imply that the algorithms, source code or computational methods implemented in **BasDonax Keyline from DEM** are derived from the Topo Drain Plugin unless explicitly indicated.

All original algorithms, hydrological analyses, computational procedures, WDI and ICL indicators, Keyline generation methods and software implementation contained in this project are the original work of the author of **BasDonax Keyline from DEM**, unless otherwise referenced.
